3. GitHub Desktop kholo. Agar repository pehle se clone hai, uska local folder dhoondo. Agar clone nahi hai:
   - File > Clone Repository > URL tab
   - https://github.com/princepatel-patelji/Food-Collecting-Game-2.0.git paste karo
   - Local path choose karo > Clone.
4. Repository ke local folder ka backup bana lo.
5. Extracted `chai-catcher-fixed` folder KE ANDAR KI SAARI FILES/FOLDERS ko copy karo. GitHub Desktop wale repository ROOT mein paste karo. Same naam ki files ke liye Replace/Overwrite choose karo. `index.html` root mein hona chahiye, `js` folder ke andar alag-alag JS files honi chahiye aur `assets/icons` ke andar icons.
6. GitHub Desktop mein Changes dekho. Summary mein likho: `Fix gameplay countdown, controls and game modes`.
7. Commit to main karo, phir Push origin dabao.
8. GitHub repository > Settings > Pages mein branch `main` aur folder `/(root)` selected rehna chahiye.
9. Deployment complete hone ke baad game kholo. Ctrl+Shift+R dabao.
10. Agar purana version aaye: Edge mein F12 > Application > Service Workers > Unregister; phir Storage > Clear site data; phir page reload.
